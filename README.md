### 🛡️ PLEXUS
**Real-Time Network Intrusion Detection System**

A live packet-capture NIDS built for actual detection, not demos — multithreaded sniffing, rule-based alerting, and a streaming dashboard that reacts as traffic happens.

- ⚡ **Scapy**-powered live packet capture & analysis
- 🔌 **WebSocket** alert streaming to the frontend
- 🔐 Token-based auth with **bcrypt** password hashing
- 🧠 ML layer in progress — RF/XGBoost on **CICIDS2017**
- 🗄️ SQLite-backed alert storage & querying

`Flask` `Scapy` `React` `SQLite` `WebSockets`

**[→ View Repository](https://github.com/Rishabh4769/Project-Plexus)**

### 🎙️ Veronica
**Native macOS AI Voice Assistant**

A desktop assistant built from the ground up — voice-driven, natively packaged, and designed to feel like part of the OS rather than a browser tab pretending to be one.

- 🌊 Voice-reactive orb + HUD-style transcript UI
- 🔊 Native `say` TTS with a Flask backend
- 🚀 LaunchAgent login-item support

`React` `Vite` `Flask` `pywebview` `AppKit`
